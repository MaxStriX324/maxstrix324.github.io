Как работает

Программа подключается к ST-Link, определяет семейство подключённого микроконтроллера по Device ID, записывает указанный BIN во внутреннюю Flash и запускает проверку записи (verify). Результаты и журнал доступны в графическом окне; сохранённые логи помогают диагностировать ошибки.

Откуда взять прошивку

После сборки проекта в PlatformIO файл обычно находится по пути .pio/build/ИМЯ_ОКРУЖЕНИЯ/firmware.bin. Для работы используется Windows PowerShell 5.1 и OpenOCD как основной способ прошивки; при наличии STM32CubeProgrammer он может использоваться как альтернативный backend. Если ни один из них не найден, установщик пытается скачать проверенную сборку xPack OpenOCD.

Ограничения и безопасность

Файл BIN не содержит достоверного указания на модель STM32 или ревизию платы. Device ID помогает определить подключённое семейство, но не подтверждает совместимость конкретной прошивки. Поддерживается BIN с адресом записи 0x08000000, без смещения стороннего загрузчика.

Программа пока не была проверена на физическом оборудовании. Перед записью необходимо сверить маркировку MCU, адрес Flash и конфигурацию сборки. При работе с силовой электроникой необходимо отключить высоковольтную часть, двигатель и исполнительные механизмы; verify не подтверждает безопасность поведения прошивки.
