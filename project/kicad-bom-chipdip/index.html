Задача

После проектирования платы экспортирую спецификацию компонентов из KiCad в CSV со столбцами Reference и Value. Произвольный CSV без этих заголовков не поддерживается. Конвертер формирует один полный TXT-файл с количеством по каждой учитываемой позиции, чтобы перенести список на сайт поиска компонентов. Компоненты DNP и исключённые из BOM позиции в закупку не попадают.

Что получает пользователь

Основной результат — файл ИМЯ_chipdip.txt. Дополнительно формируются списки подтверждённых артикулов MPN, кандидатов, таблицы для проверки и шаблон сопоставления с выбранными компонентами.

Если у компонентов нет точных артикулов, программа может вывести поисковые описания. Сопоставления из отдельного файла применяются к конкретной спецификации, а не ко всем платам автоматически.

Ограничения

Полученный TXT — список для поиска, а не готовый подтверждённый заказ. Перед покупкой необходимо сверить тип, характеристики, корпус, габариты и наличие. Конвертер не обращается к API ChipDip и не проверяет складские остатки.
