01 / FIVE TOOLS

От KiCad до измерений

PCB · BOM · COMPONENTS

01 · KiCad BOM → ChipDip

Конвертер экспортированной CSV-спецификации KiCad в полный TXT для поиска компонентов в ChipDip. Дополнительно формирует список подтверждённых артикулов и отчёты по позициям, требующим проверки.

Вход: CSV из KiCad. Выход: TXT, CSV-отчёты, шаблон сопоставления артикулов.

PCB · LASER · PYTHON

02 · KiCad SVG → LaserGRBL

Экспортирую слои печатной платы в SVG. Утилита переводит каждый файл в монохромный PNG и создаёт отчёт с физическими размерами для последующего импорта в LaserGRBL.

Вход: SVG из KiCad. Выход: PNG и TXT/CSV с размерами.

KiCad 10SVGPNGLaserGRBL

PCB · CNC · GRBL

03 · KiCad DRL → CNC3018

Конвертер читает Excellon DRL и создаёт один TAP на входной файл, объединяя координаты разных диаметров. Точки упорядочиваются по вертикальным полосам; режущие контуры могут преобразовываться в последовательность отверстий.

Вход: DRL из KiCad. Выход: G-code (.tap) для GRBL без автоматической смены инструмента. Перфорация не заменяет фрезеровку пазов.

KiCadExcellonCNC3018G-code

EMBEDDED · STM32 · ST-LINK

04 · STM32 ST-Link Flasher

Графическая прошивка STM32F103 и STM32F405 на Windows с определением семейства через ST-Link, записью firmware.bin и проверкой Flash. Сохраняется журнал операций.

Вход: BIN из PlatformIO. Выход: записанная и верифицированная Flash, лог. На реальном оборудовании ещё не проверялось.

STM32ST-LinkWindowsPowerShell

MEASUREMENTS · ARCHIVE

05 · Rigol Oscilloscope Sorter

RIGOL DHO814 и DHO924S сохраняют группы измерений в сетевую папку. Скрипт ждёт завершения записи, присваивает номер, сортирует файлы по датам, сохраняет исходники и журналы.

Вход: PNG, CSV/BIN, STP. Выход: архив, индекс измерений и XLSX для поддерживаемых форматов.

03 / OPEN SOURCE

Исходники открыты

Каждая утилита — отдельный репозиторий с инструкциями, настройками и ограничениями. Их можно скачать и адаптировать под своё оборудование.

Перед заказом компонентов необходимо подтвердить артикулы и корпуса: BOM-конвертер формирует список поиска, а не готовый заказ. Для станка и лазера проверяйте координаты, масштаб и траекторию в холостом прогоне. STM32 Flasher пока не испытан на физической плате и не может по BIN подтвердить совместимость прошивки. Rigol-сортировщик сохраняет исходные данные, но не обещает выгрузку всех цифровых каналов в XLSX.
