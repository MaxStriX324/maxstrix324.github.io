02 / WORKFLOW

Одна мастерская — пять этапов

01 / КОМПОНЕНТЫ

Спецификация

Экспортирую BOM из KiCad, получаю полный список для поиска в ChipDip и отдельно проверяю артикулы перед заказом.

02 / ПОДГОТОВКА

Лазер и плата

Экспортирую SVG и получаю монохромные PNG с параметрами физического масштаба.

03 / ИЗГОТОВЛЕНИЕ

Сверловка

Преобразую Excellon DRL в один TAP для GRBL с вертикальной сортировкой точек.

04 / ПРОШИВКА

STM32 через ST-Link

Использую BIN из PlatformIO, сверяю плату и MCU, записываю прошивку и проверяю Flash.

05 / ИЗМЕРЕНИЯ

Архив Rigol

Сортировщик превращает сохранённые файлы DHO814/DHO924S в упорядоченный архив.

03 / OPEN SOURCE

Исходники открыты

Каждая утилита — отдельный репозиторий с инструкциями, настройками и ограничениями. Их можно скачать и адаптировать под своё оборудование.

Перед заказом компонентов необходимо подтвердить артикулы и корпуса: BOM-конвертер формирует список поиска, а не готовый заказ. Для станка и лазера проверяйте координаты, масштаб и траекторию в холостом прогоне. STM32 Flasher пока не испытан на физической плате и не может по BIN подтвердить совместимость прошивки. Для Rigol DHO924S с PLA2216 практически подтверждён экспорт в Excel 20 каналов (CH1–CH4 и D0–D15); исходные файлы измерений сохраняются. Совместимость с каждым бинарным форматом требует отдельной проверки.
